## История и обслуживание

[Архив чистки](archive/2026-11-08-cleanup/README.md) содержит прежние планы, разборы,
журнал и точные резервные копии. Исторические документы не задают текущих правил и задач.
Обновлять статус выполнения и игровой проверки нужно в СОСТОЯНИЕ.md; в справочниках —
действующий алгоритм и ограничения. Завершённые планы не вести как параллельные очереди.
Большинство внутренних документов исключено из Git; перед массовыми изменениями делать backup.
